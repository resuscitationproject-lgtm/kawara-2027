# 香春町デジタルスタンプラリー　見積もり用デモ

北九州ITクラブ「KITC-KAWARA-2026-001」Ver.1.0に沿った静的Webアプリです。右上の「管理画面」から管理用IDとパスワードで見積もりを開きます。参加者はログインせずに40枚の試作カードとスタンプ帳を利用できます。

[公開デモを開く](https://resuscitationproject-lgtm.github.io/kawara-2027/)

## 起動

このフォルダで次のコマンドを実行し、ブラウザで http://localhost:8077/ を開いてください。ビルドやパッケージのインストールは不要です。

```sh
python3 -m http.server 8077 --bind 127.0.0.1
```

スマートフォンのカメラはHTTPSで配信されたページで利用します。GitHub Pagesで配信する場合はルートを公開元に指定できます。開催日は未定で、予定ドメインのDNS設定は本番準備時に行います。

## 商談での操作

1. 「管理画面」にログインしてプランを選び、「選んだプランを体験」を開きます。
2. パソコン単体では「カメラなしで操作を体験」からスポットを選びます。スタンプ帳を開き、件数と達成率を確認します。これは手動の取得体験です。
3. 実際の画像認識には、別画面の「掲示画像を見る」でカードを表示するか印刷します。カメラを起動した端末で画像全体を映し、同じカードを両プランで試します。ARプランは参考アプリの「えんぴつ」を表示します。もう一度認識しても取得数は増えません。
4. 「記録のバックアップ・復元」でバージョン2のJSONを書き出せます。復元時は署名、イベント、スタンプID、端末IDを確認し、既存の初回取得日時を優先して統合します。バージョン1のファイルは復元できないため、記録が端末に残っている場合は新しい形式で保存し直してください。

5、10、15、20、25、30、35個を新たに達成すると特典画面が表示され、スタンプ帳から再表示できます。特典内容は未定です。40個達成時は、観光協会事務局での景品受け取りとバックアップ保存を案内する画面が表示されます。達成画面もスタンプ帳から再表示できます。景品・特典の引き換え済み管理はありません。

事務局が異なる端末のバックアップを復元する機能は未実装です。利用者のブラウザだけで権限を判定すると端末制限を回避できるため、Cloudflare Accessとサーバー側の認証・認可、対象端末への安全な引き継ぎ方法を確定してから実装します。現行の管理画面のログインは見積もりデータを復号する機能で、事務局権限ではありません。

バックアップは原則として同じ端末・ブラウザで利用します。サイトデータ削除後はブラウザの特徴値を用いて復元を試みます。機種変更やブラウザ・画面設定の変更などで復元できない場合があり、同じ機種・設定の別端末で復元できる場合もあります。署名鍵は公開コードに含まれるため、改変やコピーの完全な防止はできません。端末特徴値は外部送信せずブラウザ内で計算します。iPhone Safari・Android Chromeの実機確認が必要です。

管理画面の見積もりデータは暗号化して配信します。入力したIDとパスワードから端末内で鍵を導出し、見積もりを開きます。ログアウト、ページの再読み込み、タブを閉じる操作で再ログインが必要です。

## 実装と素材

- **構成**　HTML、CSS、JavaScript。参加者のアカウント登録は不要で、イベントIDに対応するブラウザのlocalStorageに記録します。画像認識・3D表示用ライブラリも同梱しています。
- **流用元**　[まんまる文化祭ARアプリ（efafc8c）](https://github.com/resuscitationproject-lgtm/manmaru-ar/tree/efafc8c6cfe0ec14b8e23a559c47e24359da63f4)。MindARの画像ターゲット、A-FrameのアンカーによるGLB表示、イベント別保存処理、既存のえんぴつモデルを使用しています。モデル等の権利は各権利者に帰属します。
- **画像認識**　assets/cards/01.png から 40.png を番号順にMindAR 1.2.5でコンパイルしたものが assets/targets.mind です。js/spots.js の配列順に対応します。正式画像へ差し替える際は同じ順序で再コンパイルします。
- **表示素材**　トップはImageGenで制作した香春岳をモチーフにした風景イラストです。掲示カードとスポット名称は試作用です。参加施設や実際の掲示場所は未確定です。
- **ライブラリ**　A-Frame 1.6.0 と MindAR 1.2.5 を使用。ライセンスを assets/vendor/ に同梱しています。

## 本番見積もりで確定する事項

正式な施設情報と使用許諾済みのスタンプ画像・認識画像は発注者から提供いただく想定です。ARモデル、開催日、対応機種・OS、検収用画像と照明条件を確定します。独自ドメインを利用する場合は別途打ち合わせ・見積もりとします。認識データは試作40枚で約15.3MBです。正式画像への差し替え後、iPhone Safari・Android Chromeの実機で初回読み込み時間、認識距離、反射・照度の影響を確認します。景品管理・新規3D制作・全スポットの現地検証・印刷設置は別途協議します。
