# 香春町デジタルスタンプラリー　見積もり用デモ

北九州ITクラブ「KITC-KAWARA-2026-001」Ver.1.0に沿った静的Webアプリです。トップ右上の「見積もりデモ」で、AR表示付き（380,000円・税別）と画像認識のみ（230,000円・税別）を切り替えられます。どちらも同じ40枚の試作カードとスタンプ帳を使用します。

[公開デモを開く](https://resuscitationproject-lgtm.github.io/kawara-2027/)

## 起動

このフォルダで次のコマンドを実行し、ブラウザで http://localhost:8077/ を開いてください。ビルドやパッケージのインストールは不要です。

```sh
python3 -m http.server 8077 --bind 127.0.0.1
```

スマートフォンのカメラはHTTPSで配信されたページで利用します。GitHub Pagesで配信する場合はルートを公開元に指定できます。開催日は未定で、予定ドメインのDNS設定は本番準備時に行います。

## 商談での操作

1. 「見積もりデモ」でプランを選び、「選んだプランを体験」を開きます。
2. パソコン単体では「カメラなしで操作を体験」からスポットを選びます。スタンプ帳を開き、件数と達成率を確認します。これは手動の取得体験です。
3. 実際の画像認識には、別画面の「掲示画像を見る」でカードを表示するか印刷します。カメラを起動した端末で画像全体を映し、同じカードを両プランで試します。ARプランは参考アプリの「えんぴつ」を表示します。もう一度認識しても取得数は増えません。
4. 「記録のバックアップ・復元」でJSONを書き出せます。同一イベント・形式バージョン・登録済みID・取得日時を確認し、既存の初回取得日時を優先して統合します。

## 実装と素材

- **構成**　HTML、CSS、JavaScript。アカウントやデータベースは使用せず、イベントIDに対応するブラウザのlocalStorageに記録します。画像認識・3D表示用ライブラリも同梱しています。
- **流用元**　[まんまる文化祭ARアプリ（efafc8c）](https://github.com/resuscitationproject-lgtm/manmaru-ar/tree/efafc8c6cfe0ec14b8e23a559c47e24359da63f4)。MindARの画像ターゲット、A-FrameのアンカーによるGLB表示、イベント別保存処理、既存のえんぴつモデルを使用しています。モデル等の権利は各権利者に帰属します。
- **画像認識**　assets/cards/01.png から 40.png を番号順にMindAR 1.2.5でコンパイルしたものが assets/targets.mind です。js/spots.js の配列順に対応します。正式画像へ差し替える際は同じ順序で再コンパイルします。
- **表示素材**　トップはImageGenで制作した香春岳をモチーフにした風景イラストです。掲示カードとスポット名称は試作用です。参加施設や実際の掲示場所は未確定です。
- **ライブラリ**　A-Frame 1.6.0 と MindAR 1.2.5 を使用。ライセンスを assets/vendor/ に同梱しています。

## 本番見積もりで確定する事項

正式な施設情報と使用許諾済み画像、ARモデル、開催日、対応機種・OS、検収用画像と照明条件を確定します。認識データは試作40枚で約15.3MBです。正式画像への差し替え後、iPhone Safari・Android Chromeの実機で初回読み込み時間、認識距離、反射・照度の影響を確認します。景品管理・新規3D制作・全スポットの現地検証・印刷設置は別途協議します。
